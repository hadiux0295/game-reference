# rpg_sim.py — RPG · 방치형 규칙 시뮬레이션

- **검사하는 것** (`../logic.md` §3·§8의 18개 규칙): 지수 비용 곡선·일괄 구매식·벽까지 시간, 비율형 방어 데미지(0·음수 없음), 벽 감지·환생 배율 누적, 오프라인 수익 상한·시간 역행 거부, 가차 하드 천장(90/10)·50/50·10만 뽑기 경험 확률·확률표 합, 스태미나 회복, 서바이버류 3택 규칙·웨이브 밀도·XP 곡선·30분 종료.
- **실행**: `python3 -I rpg_sim.py --test` (마지막 줄 `passed k/n`, 종료 코드 = 실패 수), `python3 -I rpg_sim.py --demo` (시드 고정 요약).

- 마지막 실행: 2026-10-17, Python 3.13, `passed 18/18`.
