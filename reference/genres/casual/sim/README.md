# casual_sim.py — 캐주얼 기본 베이스 로직 검증

**무엇을 검사하나:** [`../logic.md`](../logic.md) §3의 규칙 — 매치3 처리 순서(스왑→매치→제거→낙하→리필→연쇄), 즉시 매치 없는 리필, 데드락 검사·셔플, seed 기반 결정론 리플레이, 정렬 퍼즐 역순 생성 + BFS 솔버 검증, 탐욕 봇 승률·near-miss 난이도 추정, 목숨/에너지 타임스탬프 재생·상한, "무브 +5" 컨티뉴 오퍼·재화 단일 진입점, 보상형 광고 배치 규칙, 별→장식 메타 훅. 테스트 11개.

**실행:** `python3 -I casual_sim.py --test` (마지막 줄 `passed k/n`, 종료 코드 = 실패 수) · `python3 -I casual_sim.py --demo` (시드 2026 한 판 요약). 표준 라이브러리만, 외부 의존 없음. 2026-10-17 실행 결과 `passed 11/11`.

**밸런스:** 파일 상단 `CONFIG` dict가 logic.md §2 JSON과 같은 값. README §4에 없는 값은 전부 예시값이다.

**검증하지 않는 것:** 렌더·애니메이션·입력 잠금 UI, 네트워크·서버 재검증 왕복, 결제·광고 SDK 연동(SSV 포함), 실기기 성능·백그라운드 저장, 사람 플레이어의 실제 승률(봇 승률은 레벨 간 상대 지표일 뿐), 스페셜 피스·블로커·부스터 효과, 머지 보드 자체(에너지 규칙만).
