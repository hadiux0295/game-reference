# MOBA 규칙 시뮬레이션 (sim/)

`moba_sim.py`: 1레인 1v1 MOBA의 핵심 규칙(웨이브 주기·레인 행진·미니언 교전·라스트힛 vs 패시브 골드·레벨 곡선·타워 타겟팅/플레이트·오브젝트 현상금 상한·셧다운 억제·사망 타이머·상점·넥서스 승리)을 순수 Python 3 표준 라이브러리로 돌리는 결정론적(`random.Random(seed)`) 시뮬레이션. 밸런스는 상단 `CONFIG` dict 하나(= [`../logic.md`](../logic.md) §2 JSON)에서만 읽는다.
```bash
python3 -I moba_sim.py --test   # 테스트 11개, 마지막 줄 `passed 11/11`, 종료 코드 = 실패 수
python3 -I moba_sim.py --demo   # 시드 10으로 한 판 요약 (현상금 활성 5:00 = 모바일 압축 예시값)
```
확인: 2026-10-17, Python 3.13, `passed 11/11`. 테스트 이름은 `logic.md` §3 "검증" 항목과 1:1.

**검증하지 않는 것**: 렌더·입력·UI, 네트워크(서버 스냅샷, 락스텝 동기), 실기기 성능, 3레인·정글·스킬 체계, 5v5 팀 전투 AI, 매치메이킹. 1초 틱·1차원 레인·확률 기반 영웅 AI(라스트힛 성공률·교전 확률)는 규칙 검증용 단순화이며 실제 체감 밸런스를 보장하지 않는다.
