# shooter_sim.py

`../logic.md` §3의 슈팅 핵심 규칙을 표준 라이브러리만으로 검사하는 결정론 시뮬레이션. 밸런스는 파일 상단 `CONFIG`(logic.md §2 JSON과 동일 값).

- **검사하는 것**: 무기 데미지·거리 감쇠·TTK, hitscan 최근접 판정, 투사체 리드샷, 되감기 버퍼 랙 보상(허용 폭 안 수락·밖 거부), 입력 재생 리컨실리에이션, 스폰 점수·스폰 보호, 데스매치 킬/시간 종료, MR12 연장, 구매 라운드 경제, BR 서클 축소 스케줄.
- **실행**: `python3 -I shooter_sim.py --test` (마지막 줄 `passed k/n`, 종료 코드 = 실패 수) · `python3 -I shooter_sim.py --demo` (시드 7, 8인 데스매치 요약).
- **결과**: `passed 17/17` (2026-10-17, Python 3.13).
- **검증하지 않는 것**: 렌더링·애니메이션, 실제 네트워크 지연·패킷 손실, 3D 히트박스(2D 원으로 단순화), 보간·스윕 충돌, 반동·탄퍼짐, 실기기·Roblox/Godot 엔진 동작, 서버 성능.
