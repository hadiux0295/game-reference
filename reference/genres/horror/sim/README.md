# horror_sim: 호러·판별 규칙 시뮬레이션

[`../logic.md`](../logic.md) §3의 규칙을 순수 Python 3(표준 라이브러리만, `random.Random(seed)`로 결정론)으로 검사한다. 밸런스는 파일 상단 `CONFIG`(logic.md §2 JSON과 같은 값), 이상현상 풀·규칙·수작업 손님은 그 아래 데이터 테이블에 있다.

- **검사하는 것:** 이상현상 무중복 뽑기(해금 집합 안에서, 소진 시 리필), 수작업 2~3명 + 절차 생성 혼합, 밤마다 규칙 1~2개 누적과 공지 상태에서만 전달, 벌점 사다리(2회 면제 → 5, 5, 10, 15, 20…, 밤마다 리셋), 위협 게이지 게임 오버와 리셋, 서류 대조(정상 서류 오탐 0 · 데이터 이상현상 5종 전부 적발), 밤 타이머 종료, 밤별 이상현상 비율 상승, 치명형 밤당 1회 + 직전 손님 예고, 발견률 로그의 "너무 미묘" 플래그, 같은 시드 재현성. 테스트 15개.
- **실행:** `python3 -I horror_sim.py --test` (마지막 줄 `passed k/n`, 종료 코드 = 실패 수) · `python3 -I horror_sim.py --demo --seed 2026` (한 판 요약).
- **검증하지 않는 것:** 렌더·연출(점프스케어, 조명, 사운드), 네트워크·협동(텔레포트, 매칭, 판정 잠금의 동시성), 실기기 성능, 실제 만세력(절기 시각·서머타임 — 입춘을 고정 날짜로 둔 예시 공식), 실제 플레이어의 발견률(`visibility`는 봇용 예시값).
