# data/: 참고 게임 수치 (전투 · 레벨링 · 경제 · 상점)

다른 게임의 **숫자와 규칙**(업그레이드 비용, 경험치 곡선, 웨이브당 수입, 상점 가격)을 모아 두는 곳입니다.
`systems/`가 "어떻게 설계하나"라면, `data/`는 "잘 팔리는 게임은 실제로 몇으로 했나"입니다. 시작일 **2026-10-15**.

## 출처 표기 (모든 수치 행에 필수)
| `source:` | 뜻 | 신뢰 |
|---|---|---|
| `wiki` | 공개 위키·공식 페이지·커뮤니티 가이드에 적힌 값 (URL + 확인일) | 원문이 있으면 그대로 믿음 |
| `measured` | 우리가 직접 플레이하며 잰 값 (영상 프레임, 스크린샷) | 측정 방법을 함께 적음 |
| `extracted` | 우리가 소유한 게임의 데이터 파일(JSON, ScriptableObject 등)에서 읽은 값 | 파일·버전 적음 |
| `decompiled` | 우리가 소유한 게임의 코드를 읽어 얻은 값 | 버전 적음 · 코드는 옮겨 적지 않음 |
| `inferred` | 위 값들로 우리가 계산·추정한 값 | 계산식 적음 |

출처가 없는 수치는 넣지 않습니다. 확인하지 못했으면 `미검증`이라고 적습니다.

## 수집 사다리 (답이 나오는 단계에서 멈춤)
| 단계 | 방법 | 기본값 |
|---|---|---|
| R0 | 공개 위키, 데이터마이닝 사이트, 개발자 강연, 직접 플레이 측정 | **항상 여기부터** |
| R1 | 소유한 게임의 데이터 파일만 열람 | 필요할 때 결정 |
| R2 | 소유한 PC 게임(Unity Mono · Godot)의 코드 열람 | 필요할 때 결정 |
| R3 | IL2CPP · 네이티브 · 모바일 APK | 하지 않음 |
| ✗ | Roblox 등 온라인 게임 클라이언트 | **절대 하지 않음** (약관 위반, 계정 정지) |

- 한국 저작권법 §101조의4는 호환 목적의 역분석만 허용합니다. 기본은 R0입니다.
- 적는 것은 **숫자, 곡선, 규칙을 말로 정리한 것**뿐입니다. 남의 코드는 옮겨 적지 않습니다.
