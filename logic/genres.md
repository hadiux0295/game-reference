# 장르별 게임 로직

장르마다 **핵심 루프**, **필요한 시스템**, **구현 함정**을 정리했습니다.
공통 시스템(루프, FSM, RNG, 경제, 저장 등)은 [`core_systems.md`](core_systems.md)를 참고하세요.

**적합 플랫폼 표기**
- 📱 앱 게임
- 🟥 Roblox
- 둘 다 적합하면 📱🟥

## 공통 코어 루프

```
행동(Action) → 보상(Reward) → 성장(Progression) → 더 큰 행동 해금
     ↑                                                    │
     └────────────── 다음 세션 재방문 동기 ←──────────────┘
```

## 📱 하이퍼캐주얼
- **루프:** 원터치 조작 → 30초~2분 세션 → 점수·레벨 → 즉시 재시작
- **시스템:**
  - 레벨 생성기: 수작업 레벨과 절차적 생성 혼합, 난이도 곡선
  - 즉각 피드백: 화면 흔들림, 파티클, 햅틱, 사운드 피치 상승
  - 인터스티셜 광고와 보상형 광고 타이밍
- **함정:**
  - 첫 3초 안에 조작을 이해시키지 못하면 이탈합니다. 튜토리얼은 텍스트가 아니라 손가락 애니메이션으로 보여 주세요.
  - 광고 빈도가 과하면 D1 리텐션이 급락합니다. 최소한 레벨 N 이후, M초 쿨다운을 두세요.
- **연결:** 메인 저장소의 `hyper_casual_analysis.md` 원칙(즉각 피드백, 짧은 세션, 불규칙 보상)

## 📱 퍼즐 (매치-3, 블록, 2048류)
- **루프:** 퍼즐 해결 → 별·코인 → 다음 레벨, 막히면 부스터
- **시스템:**
  - 보드 상태: 2차원 배열. 렌더와 완전히 분리합니다.
  - 매치-3 처리 순서: 스왑 → 매치 탐색 → 제거 → 낙하 → 리필 → 연쇄 반복 → 매치가 없으면 셔플
  - **데드락 검사**: 가능한 수가 하나도 없으면 셔플합니다.
  - 레벨 데이터: JSON으로 보드 배치, 목표, 이동 횟수를 정의합니다.
- **함정:**
  - 애니메이션 중에 입력을 받으면 보드가 꼬입니다. 처리 중에는 입력을 잠그세요(FSM으로 관리).
  - 리필 시 즉시 매치가 생기지 않게 생성 규칙을 둡니다.
- **2048 핵심:** 한 방향으로 미끄러뜨리기는 "압축 → 병합 → 압축"입니다. 네 방향은 보드를 회전시켜 한 함수로 처리합니다.

## 📱🟥 방치형 / 시뮬레이터
- **루프:** 클릭·자동 생산 → 재화 → 업그레이드(지수 비용) → 벽 → 리버스 → 영구 배율
- **시스템:**
  - 오프라인 수익: `(now − lastSeen) × 초당생산 × 효율`. 상한(예: 8시간)을 둡니다.
  - 큰 수 표기 (1.2K, 3.4M, 5.6aa…)
  - 업그레이드 트리, 펫·장비 뽑기(가중치 + 천장)
- **함정:**
  - **기기 시간 조작**으로 오프라인 수익을 부풀릴 수 있습니다. 온라인이면 서버 시간을, 오프라인이면 마지막 저장 시각보다 이전으로 돌아간 시간을 무시하세요.
  - 소수점 누적 오차가 생길 수 있습니다.
- 🟥 Roblox 시뮬레이터는 여기에 펫 뽑기와 지역 해금, 리버스를 더한 형태입니다.

## 📱🟥 러너 / 액션 아케이드
- **루프:** 자동 전진 → 장애물 회피 → 거리·코인 → 캐릭터 해금
- **시스템:**
  - 청크 기반 맵 생성: 미리 만든 구간 조각을 난이도별로 이어 붙입니다.
  - 오브젝트 풀링: 장애물과 코인을 재사용해 GC 끊김을 막습니다.
  - 속도 곡선: 시간에 따라 증가하되 상한을 둡니다.
- **함정:**
  - 히트박스가 보이는 것보다 크면 불공정하게 느껴집니다. **보이는 것보다 살짝 작게** 잡으세요.

## 🟥 Obby (장애물 코스)
- **루프:** 점프 → 체크포인트 → 다음 스테이지
- **시스템:** 스테이지 번호 저장, 킬 파트, 움직이는 발판
- **함정:** 체크포인트 순서를 **서버에서 검증**하세요 (`stage == current + 1`). 하지 않으면 스킵 치트가 가능합니다.
- **수익화:** 스테이지 스킵(소모성 상품), 속도·점프 패스

## 🟥 타이쿤
- **루프:** 드로퍼 생산 → 수집 → 버튼 구매 → 생산 확장
- **시스템:** 플레이어별 플롯 할당·반납, 구매 버튼 의존성 트리, 오프라인 수익
- **설계:** 버튼, 가격, 선행 조건을 Config 테이블로 둡니다. 저장은 **구매한 버튼 ID 목록만** 하고, 접속 시 플롯을 재구성합니다.

## 📱🟥 라운드제 (미니게임, 서바이벌, 술래잡기, 파티게임)
- **루프:** 로비 → 인터미션 → 라운드 → 결과 → 반복
- **시스템:** 상태 머신, 맵 로테이션, 팀 배정, 관전
- **함정:** 라운드 중 이탈이나 사망으로 남은 인원이 1명 이하가 되면 즉시 종료해야 합니다.
- **구현:** [`../platforms/roblox/patterns/RoundService.luau`](../platforms/roblox/patterns/RoundService.luau)

## 📱🟥 타워 디펜스
- **루프:** 웨이브 → 처치 보상 → 타워 배치·업그레이드 → 다음 웨이브
- **시스템:**
  - 경로: 웨이포인트 배열 또는 플로우 필드
  - 타겟팅 규칙: First, Last, Strongest, Closest
  - 웨이브 정의: 데이터 테이블
- **성능:** 적이 수백 마리면 무거운 물리 객체 대신 **좌표만 시뮬레이션**하고 렌더는 분리하세요. ECS와 오브젝트 풀링이 유리합니다.

## 📱🟥 전투 / RPG
- **데미지 공식 예:** `dmg = atk × skillMul × (100 / (100 + def)) × crit × rand(0.95, 1.05)`. 방어력은 감산형이 아니라 비율형으로 만들어야 0 데미지 문제가 없습니다.
- **히트 판정:** 레이캐스트나 쉐이프캐스트를 씁니다. 반응성을 위해 클라이언트에서 판정하더라도 **서버 재검증**이 필요합니다.
- **상태 이상:** `{ type, stacks, expiresAt }` 목록으로 관리하고, 매 틱마다 만료를 정리합니다.
- **스킬 쿨다운:** 남은 시간을 매 프레임 줄이지 말고 **만료 시각(timestamp)**을 저장하세요.

## 수익화 체크리스트
- [ ] 영구 구매: 광고 제거 📱, VIP·2배 재화 패스 🟥

- [ ] 과도한 Pay-to-win 금지: 리텐션이 하락하고 연령 정책 리스크가 있습니다
